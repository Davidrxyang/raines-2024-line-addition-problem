`find -name "*.java" > sources.txt`

`javac @sources.txt`

alternatively: 

`./build`

(make sure permissions for the bash script are set properly)

to run the algorithm:

`java Algorithm.Main CONFIG_FILE`

where CONFIG_FILE is the path to the config parameter file.
